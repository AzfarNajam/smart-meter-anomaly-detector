# logs/

This folder holds three structured JSON-line logs, generated by
`src/logger_config.py`:

- **detection.log** — every anomaly a detector flags (the *what*)
- **operational.log** — whether the detection pipeline itself is healthy
  (the *is the watcher still watching*)
- **audit.log** — any change to thresholds/configuration (the *who changed
  what, and why*)

These are kept as three separate files rather than one combined log,
deliberately — it mirrors how real security monitoring systems separate
concerns so each question ("what got flagged," "is the system alive,"
"what changed") can be investigated independently.

Log files themselves are **not** committed to git (see `.gitignore`) —
they're generated output, not source code. Run this to generate sample
entries locally:

```
python tests/test_logging.py
```
